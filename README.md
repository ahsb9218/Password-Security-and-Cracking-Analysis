# 🔐 Password Security & Cracking Analysis

## 📌 Project Overview

This project demonstrates **Password Security & Cracking Analysis** using **Kali Linux** and various cybersecurity tools. It explains password hashing, hash identification, wordlist generation, and password auditing in a **controlled educational environment**.

---

## 🎯 Objectives

* Understand password security concepts
* Generate SHA-256 password hashes
* Identify hash types using HashID
* Generate custom wordlists using Crunch
* Analyze password hashes using John the Ripper
* Learn the importance of strong and unique passwords

---

## 🛠️ Tools Used

* Kali Linux
* John the Ripper
* Crunch
* OpenSSL
* HashID

---

## 🔒 Security Recommendations

* Use passwords of at least 12 characters
* Include uppercase and lowercase letters
* Include numbers and special characters
* Avoid common dictionary words
* Enable Multi-Factor Authentication (MFA)
